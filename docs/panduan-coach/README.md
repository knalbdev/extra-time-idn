# Panduan penilaian untuk coach

Buka `editor.html` dengan browser (klik dua kali file). Halaman dapat digunakan langsung tanpa menjalankan website atau server lokal.

1. Pilih coach. Username awal mengikuti akun yang disiapkan: `coach.renang`, `coach.panahan`, `coach.berkuda`, `coach.taekwondo`, `coach.pramuka`.
2. Periksa alamat portal. Alamat awal `https://extra-time-idn.vercel.app/coach` dapat diubah sesuai domain yang digunakan.
3. Isi password akun coach yang sudah dibuat. Sesuaikan username bila berbeda. Isian ini tidak membuat atau mengubah akun.
4. Periksa pratinjau. PNG mencantumkan password secara utuh, sehingga hanya dibagikan kepada coach yang bersangkutan.
5. Pilih **Unduh PNG coach ini**, atau lengkapi semua coach lalu **Unduh ZIP berisi 5 PNG**. Nama berawalan `DRAF-` berarti password belum diisi.
6. Untuk WhatsApp, kirim PNG sebagai dokumen agar teks tidak dikompresi. Jangan mengirim ZIP berisi semua akun ke grup coach.

Isian hanya berada dalam memori halaman; tidak memakai penyimpanan browser, koneksi internet, atau layanan ekspor lain. Menutup/memuat ulang halaman mengosongkan password. File HTML sumber tetap tidak berisi password yang dimasukkan. Tombol **Kosongkan semua password** dapat digunakan sebelum halaman ditutup.

PNG draf dan ZIP awal ada di `artifacts/panduan-coach/`. Folder ini diabaikan Git karena hasil final nantinya dapat berisi password. Editor berada di `docs/`, bukan `public/`, sehingga tidak dipublikasikan sebagai halaman website.

Isi panduan mengikuti portal saat ini: pertemuan per kelas, materi/skill inti, kehadiran, predikat A–E, catatan opsional, penyimpanan tiap siswi, penguncian materi setelah dinilai, refresh, dan logout. Predikat hanya untuk siswi hadir. Laporan diunduh oleh admin. Panduan Pramuka digunakan setelah ruang coach diaktifkan kembali.
