Siapkan panduan untuk masing-masing coach

Lengkapi akun, periksa pratinjau, lalu unduh PNG. Setiap gambar hanya memuat akun coach yang dipilih. Halaman ini dapat digunakan tanpa koneksi internet.

Pastikan alamat ini sesuai dengan web yang akan digunakan.

Sesuaikan jika username akun berbeda dari isian awal.

Password akan terlihat pada PNG. Isikan password akun yang sudah dibuat; halaman ini tidak membuat atau mengganti akun.

Memuat pratinjau…

Pramuka: panduan digunakan setelah ruang coach diaktifkan oleh admin.

Isian akun hanya diproses di halaman ini, tidak dikirim ke server dan tidak disimpan di browser. Mengunduh PNG tidak menyimpan isian ke file HTML.

Kirim tiap PNG hanya kepada coach yang bersangkutan. Pilih kirim sebagai dokumen agar teks tetap jelas.
